# Varredura semanal de domínios

## Em uma frase

Quando estiver pronto, vai existir uma varredura semanal que procura variações
do meu domínio e três frases minhas na web, e produz uma ficha datada para
cada loja que encontrar.

## O que faz

Uma vez por semana: (1) gera as variações do domínio a partir de uma lista
escrita à mão — letra trocada, hífen a mais, outro sufixo — e confere quais
estão registradas; (2) busca três frases minhas improváveis de aparecer por
acaso; (3) para cada achado, grava uma ficha com data, o que bateu e um print.
Detecta. **Não notifica ninguém** — isso é outra decisão, e está pendente.

## Para quem

Eu, quando a próxima cliente perguntar "essa loja é sua?" — para responder com
uma ficha, não com um susto.

## Pronto quando

- [ ] Quatro semanas seguidas de varredura, com a ficha de cada achado datada
- [ ] A loja que a cliente comprou (a do print de agosto) aparece na primeira
      varredura — se não aparecer, o método está errado
- [ ] Um achado duvidoso (revendedor legítimo) fica marcado como duvidoso, não
      some
