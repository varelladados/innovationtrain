# _historico de 2-notas

O que já avançou daqui. **Nada é apagado:** quando um item passa para o estágio
seguinte, o original vem para cá com o texto preservado como estava e um rodapé
apontando para onde foi.

Está vazio? Então nada avançou deste estágio ainda.

---

*Este arquivo existe também por um motivo prático: git não versiona pasta vazia,
e sem ele esta pasta simplesmente não existiria num clone novo — a plataforma
chegaria quebrada na máquina de quem clonasse. Foi o CI que pegou.*
